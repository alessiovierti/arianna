# Arianna documentation

This is the public documentation for Arianna. The project name is **Arianna**; the installed executable and CLI command are **`learn`**.

## Documentation policy

Implemented behavior is documented in the focused guides above. `roadmap.md` is the source of truth for future work and non-goals; a planned feature must not be described as available until it is implemented and tested.
